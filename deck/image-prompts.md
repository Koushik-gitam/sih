# Optional AI image prompts for the deck

The deck in `slides.html` is built with pure CSS/SVG diagrams, so it needs **no images** to
look finished. If the team wants richer visuals, generate the graphics below (16:9) and drop
them into the matching slides.

Design system to keep every image consistent:

| Token | Value |
|---|---|
| Primary | Deep Navy `#0A192F` |
| Accent | Emerald Teal `#00B4D8` |
| Cards | Crisp White `#FFFFFF` |
| Background | Light Gray `#F8FAFC` |
| Pass / Fail | `#10B981` / `#EF4444` |

| Slide | Prompt |
|---|---|
| 1 — Cover | High-tech minimalist vector illustration of a digital precision weighing scale balance integrated with data streams and a digital security certificate shield, deep navy blue and emerald teal colour scheme, white background, clean SaaS banner aesthetic, 16:9 |

## Export reminders

1. Keep the deck at **10 slides** and do not rename mandatory section titles.
2. Body text must stay **≥ 16–18 pt**; slide titles 28–32 pt.
3. Export to PDF (`npm run deck:pdf`) and confirm the file is **under 10 MB** before uploading.
